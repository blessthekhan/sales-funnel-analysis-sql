# Sales Funnel Analysis Using SQL

## Project Overview

This project analyzes user behavior across an e-commerce sales funnel using SQL. The goal is to understand how users progress from viewing a page to completing a purchase, identify major drop-off points, and evaluate the performance of different traffic sources.

## Business Questions

The analysis explores the following questions:

- How many users reach each stage of the sales funnel?
- What are the conversion rates between different funnel stages?
- What is the overall conversion rate from page view to purchase?
- Which traffic sources generate the most traffic?
- Which traffic sources have the highest conversion rates?
- Where do the largest user drop-offs occur?
- How long does the journey from page view to purchase take?

## Funnel Stages

The sales funnel consists of five stages:

1. Page View
2. Add to Cart
3. Checkout Start
4. Payment Information
5. Purchase

## Analysis Performed

### 1. Initial Data Exploration
Analyzed the frequency of different event types and evaluated the amount of traffic generated by each traffic source.

### 2. Funnel Analysis
Calculated the number of unique users at each stage of the sales funnel.

### 3. Conversion Analysis
Measured conversion rates between consecutive funnel stages and calculated the overall conversion rate from page view to purchase.

### 4. Traffic Source Analysis
Compared traffic sources based on the number of visitors, cart conversions, purchases, and overall conversion rates.

### 5. Time Analysis
Explored the time taken by users to move through the sales funnel and complete a purchase.

### 6. Drop-Off Analysis
Identified user drop-offs between funnel stages and compared drop-off patterns across different traffic sources.

## Key Insights

- Organic traffic generated the highest number of visitors.
- Email generated the highest overall conversion rate of approximately 33%.
- A significant drop-off of approximately 68% occurred between the page view and add-to-cart stages.
- Email had the lowest overall drop-off rate, while social media showed the highest drop-off rate.

## Recommendations

- Explore opportunities to scale effective email marketing campaigns, as email traffic showed the strongest overall conversion performance.
- Investigate the large drop-off between page view and add-to-cart by reviewing the website experience, product presentation, pricing, and potential incentives.
- Review social media traffic quality and campaign targeting to understand why users from this source have a higher drop-off rate.
- Further analyze user-level journey data to better understand the time required to complete a purchase.
